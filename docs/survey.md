# 현장 설문 (1분)

| 항목 | 내용 |
|---|---|
| 상태 | 초안 (2026-10-03, K-Builder 현장) |
| 기준 문서 | `docs/PRD.md` v0.4 13절 「현장 설문」 5문항. 4절(설문으로 WHO를 숫자로 만든다) |
| 대상 | 현장 참가자 15~20명 (PRD 13절). 우리 팀원은 답하지 않는다 |
| 소요 | 1분 이내 목표. 5문항 모두 하나만 고른다 |
| 받지 않는 것 | 이름, 연락처, 학번, 학과, 팀 이름. 칸 자체를 두지 않는다 |
| 담당 | 현찬 (PRD 12절 제안) |

## 1. 진행 규칙

1. 설문 전에 우리 서비스를 설명하거나 데모를 보여 주지 않는다. 먼저 보면 3번과 5번 답이 우리 쪽으로 기운다.
2. 문항은 적힌 그대로 읽거나 보여 준다. 뜻을 물으면 "적힌 대로 판단해 주시면 됩니다"라고만 답한다.
3. 답하기 싫은 문항은 건너뛰게 한다. 건너뛴 칸은 무응답으로 둔다.
4. 시작한 뒤에는 문항과 선택지를 바꾸지 않는다. 바꾸면 그 전 응답과 합쳐 셀 수 없다.
5. 기록표의 응답자 번호 옆에 이름, 팀 이름, 인상착의를 적지 않는다. 번호는 받은 순서일 뿐이다.
6. 한 사람에게 한 번만 받는다.

## 2. 시작할 때 하는 말

> 국민대 공지와 지원서에 관한 1분 설문입니다. 이름, 연락처, 학번은 받지 않습니다. 답하기 싫은 문항은 건너뛰셔도 됩니다. 결과는 오늘 발표에서 응답 수와 함께 씁니다.

## 3. 설문지 (인쇄하거나 화면에 띄운다)

응답자 번호: ______ (진행자가 적는다)

**1. 최근 1년 동안, 학교 공지나 대외활동 공고를 늦게 알아서 신청이나 지원 기회를 놓친 적이 있습니까?**

- ☐ ① 없다
- ☐ ② 1번
- ☐ ③ 2번 이상
- ☐ ④ 기억나지 않는다

**2. 학교 공지나 대외활동 공고를 보려고 한 달에 한 번 이상 들어가 보는 곳은 몇 군데입니까?** (사이트, 앱, 단체 채팅방, SNS 계정을 모두 셉니다)

- ☐ ① 따로 찾아보지 않는다
- ☐ ② 1곳
- ☐ ③ 2~3곳
- ☐ ④ 4곳 이상

**3. 관심 분야로 고른 학교 공지와 공고만 모아서 알려 주는 무료 서비스가 있다면 쓰겠습니까?**

- ☐ ① 쓰겠다
- ☐ ② 써 보고 정하겠다
- ☐ ③ 쓰지 않겠다
- ☐ ④ 잘 모르겠다

**4. 공모전, 대외활동, 채용 지원서에 같은 기본 정보(이름, 연락처, 학과 등)를 다시 적는 일은 어떻습니까?**

- ☐ ① 번거롭다
- ☐ ② 보통이다
- ☐ ③ 번거롭지 않다
- ☐ ④ 지원서를 써 본 적이 없다

**5. 포트폴리오 PDF를 올리면 외부 AI가 읽고 내 이력을 정리해, 맞는 공고를 추천하는 기능이 있다면 쓰겠습니까?**

- ☐ ① 쓰겠다
- ☐ ② 써 보고 정하겠다
- ☐ ③ 쓰지 않겠다
- ☐ ④ 올릴 포트폴리오가 없다
- ☐ ⑤ 잘 모르겠다

### 3-1. PRD 문항에서 바꾼 곳과 이유

| 번호 | PRD 13절 원문 | 바꾼 점 | 이유 |
|---|---|---|---|
| 1 | 학교 공지나 대외활동 공고를 놓쳐서 손해 본 적이 있나? | 「손해」를 「늦게 알아서 신청이나 지원 기회를 놓친 적」으로 바꾸고, 기간을 최근 1년으로 묶었다 | 「손해」는 사람마다 범위가 달라 셀 수 없다. 기간이 없으면 오래 다닌 사람일수록 「있다」가 늘어난다 |
| 2 | 공지를 보려고 평소 몇 군데를 확인하나? | 「평소」를 「한 달에 한 번 이상」으로 정하고, 세는 범위를 적었다 | 기준을 맞춰야 응답끼리 비교된다 |
| 3 | 고른 분야만 알려 주면 쓰겠나? | 무료라는 조건을 적고, 「써 보고 정하겠다」를 넣었다 | PRD 4절대로 학생에게는 무료다. 망설이는 사람이 「쓰겠다」로 몰리지 않게 중간 선택지를 뒀다 |
| 4 | 지원서마다 같은 정보를 다시 적는 게 귀찮나? | 「귀찮나?」를 「어떻습니까?」로 바꾸고, 3단계와 「써 본 적이 없다」를 뒀다 | 「귀찮나」는 답을 한쪽으로 미는 질문이다. 지원 경험이 없는 사람은 따로 센다 |
| 5 | 포트폴리오를 올리면 맞는 공고를 추천해 주는 기능을 쓰겠나? | 외부 AI가 읽는다는 사실을 넣고, 「올릴 포트폴리오가 없다」를 뒀다 | 실제 기능은 PDF에서 뽑은 글을 외부 AI로 보낸다(PRD 6-1). 이걸 빼고 물으면 의향이 실제보다 높게 나올 수 있다. 포트폴리오가 없는 사람을 「쓰지 않겠다」와 섞지 않는다 |

## 4. 소요 시간

- 5문항 모두 하나만 고른다. 문항당 10초로 잡으면 50초다. 이 값은 추정이고 실측이 아니다.
- 처음 두 명은 휴대폰 스톱워치로 「시작할 때 하는 말」부터 마지막 답까지 재서, 기록표 위에 적는다.
- 1분이 넘으면 시작할 때 하는 말을 줄인다. 문항은 그대로 둔다(1절 4번).

## 5. 응답 기록표

### 5-1. 적는 법

- 설문지의 ①~⑤를 숫자 1~5로 적는다.
- 무응답은 종이에는 `-`, 화면에서는 빈칸으로 둔다.
- 응답자가 설문지에 직접 표시했다면, 진행자가 그 종이에 번호를 적고 나중에 아래 표로 옮긴다.

### 5-2. 한 사람 한 줄 (종이·화면 공용)

### 5-3. 집계표

| 문항 | ① | ② | ③ | ④ | ⑤ | 무응답 | 응답 수 (무응답 제외) |
|---|---|---|---|---|---|---|---|
| 1 | | | | | 없음 | | |
| 2 | | | | | 없음 | | |
| 3 | | | | | 없음 | | |
| 4 | | | | | 없음 | | |
| 5 | | | | | | | |

- 스프레드시트에서는 `=COUNTIF(B2:B21,1)`처럼 센다. B열이 문항 1이고 마지막 숫자가 선택지 번호다. 무응답은 `=COUNTBLANK(B2:B21)`로 센다. 범위는 실제로 응답자가 있는 줄까지만 잡는다. 빈 줄까지 잡으면 무응답이 부풀어 오른다.
- 두 사람이 따로 세어 같은 숫자가 나오면 확정한다.

## 6. 결과를 발표에 쓸 때 규칙

1. **응답 수를 항상 같이 쓴다.** 「N명 중 M명(P%)」처럼 사람 수를 먼저 쓰고, 퍼센트는 괄호에 넣는다. 퍼센트만 쓰지 않는다. 15~20명이면 한 명이 5~7%p를 움직인다.
2. **분모는 그 문항에 답한 사람 수다.** 무응답은 분모에서 빼고, 몇 명인지 따로 적는다. 4번의 「④ 지원서를 써 본 적이 없다」나 5번의 「④ 올릴 포트폴리오가 없다」를 분모에서 뺐다면 문장에 그렇게 밝힌다.
3. **반올림.** 퍼센트는 소수 첫째 자리에서 반올림해 정수로 쓴다. 0.5는 올린다. 계산 예: 11/18 = 61.1% → 61%, 1/8 = 12.5% → 13%. 더해서 100%가 안 돼도 맞추려고 숫자를 고치지 않는다.
4. **합친 선택지는 합쳤다고 쓴다.** 3번의 ①과 ②를 합치면 「쓰겠다거나 써 보고 정하겠다고 답한 사람」이다. 이 합을 「쓰겠다」라고 부르지 않는다. 1번의 ②와 ③을 합친 것은 「놓친 적이 있다고 답한 사람」이다.
5. **누구에게 물었는지 쓴다.** 「K-Builder 현장 참가자 N명(2026-10-03)」으로 쓴다. 「국민대생」이나 「대학생」으로 넓히지 않는다. 해커톤에 온 사람들이라 IT와 창업에 관심이 많은 쪽으로 치우쳤을 수 있다(추정).
6. **의향은 의향으로 쓴다.** 3번과 5번은 「쓰겠다고 답했다」로 쓴다. 「쓴다」나 「수요가 확인됐다」로 바꾸지 않는다. 돈을 낼지는 묻지 않았다. 그래서 PRD 4절 MONEY 가설(H1, H2)의 근거로 쓰지 않는다.
7. **결과가 기대와 달라도 그대로 쓴다.** 응답을 빼거나 고치지 않는다. 같은 사람에게 다시 묻지 않는다.
8. **작게 쪼개지 않는다.** 응답자가 적어서 하위 집단끼리 비교하지 않는다. 학년이나 학과는 묻지도 않았다.
9. **원 기록을 남긴다.** 종이는 발표가 끝날 때까지 보관하고, 기록표 사진을 한 장 찍어 둔다. 사진에 사람 얼굴이나 이름이 나오지 않게 한다.
10. **그래프에도 표본 수를 적는다.** 막대그래프를 쓰면 제목이나 축 이름에 「N명」을 넣는다.

### 6-1. 문장 예

N, M, P 자리에 실제로 센 숫자를 넣는다. 아래 문장의 형태만 가져다 쓴다.

| 쓸 수 있는 형태 | 쓰면 안 되는 형태 | 왜 안 되나 |
|---|---|---|
| K-Builder 현장 참가자 N명 중 M명(P%)이, 최근 1년 안에 공지를 늦게 알아 신청 기회를 놓친 적이 있다고 답했습니다. | 대학생 P%가 공지를 놓칩니다. | 대상이 넓어졌다. 표본 수가 없다. 「답했다」가 「놓친다」로 바뀌었다 |
| 응답한 N명 중 M명(P%)이 분야 맞춤 알림 서비스를 쓰겠다고 답했습니다. 「써 보고 정하겠다」는 K명입니다. | 참가자 대부분이 우리 서비스를 원합니다. | 「대부분」의 기준이 없다. 의향을 수요로 바꿨다. 중간 선택지를 숨겼다 |

## 7. 각 문항이 받치는 것과 못 받치는 것

| 문항 | PRD에서 받치는 것 | 이 문항으로는 말할 수 없는 것 |
|---|---|---|
| 1 | 2절 문제. 공지를 늦게 알아 기회를 놓친다 | 놓친 손해가 얼마나 큰지 |
| 2 | 2절 「출처가 흩어져 있다」 | 어느 출처가 중요한지 |
| 3 | 핵심 기능(분야 맞춤 알림)을 쓸 의향. 4절의 WHO 숫자 | 실제 사용률, 돈을 낼 의향 |
| 4 | 지원 준비 기능(P3)이 덜어 줄 번거로움 | 자동 채우기를 실제로 쓸지 |
| 5 | 포트폴리오 분석 추천(P2)을 쓸 의향 | 쓰지 않겠다는 이유. 개인정보 걱정 때문인지 묻지 않았다 |

## 8. 팀이 정할 것

1. 국민대 재학생인지 묻는 문항을 더할지. 지금은 묻지 않는다. 더하면 6문항이 되고, 6절의 결과 문장을 「국민대 재학생 참가자」로 좁힐 수 있다. 대신 응답자가 적을 때 「아니오」가 한두 명이면 그 사람이 드러날 수 있다.
2. 설문을 누가 언제 돌릴지. PRD 13절은 T+0:30까지 문항 5개를 확정한다고 적었다.
3. 종이와 화면 중 무엇으로 받을지.
